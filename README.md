# Azilos releases

Azilos is installed on your own server. This repository holds what you need to install it: each
version's install bundle and release notes, and the install guides. The source code is not here.

## Install

1. Read [the installation guide](docs/operations/installation-guide.md). The guides appear here with
   the first release published from this repository.
2. Download `azilos-deploy-<version>.tar.gz` from [Releases](https://github.com/Valintes/azilos-releases/releases).
3. Run the image it names, `ghcr.io/valintes/azilos:<version>`.
